## Description

Data Archivist est mon cinquieme projet de la picine python de 42. Le but est de toujours ce famialiariser et de voir les base du python avec des exercices simples.

## Detail

| Exercices | Role |
|-----------|------|
| ex0 | Le but de cet exercice est de utiliser les fonction qui permet d'ouvrir, lire et ferme un fichier txt avec les fonctions open().... |
| ex1 | Le but de cet exercice est de re utiliser ce qui a etait vu dans l'exercice 0 mais cette fois-ci de modifier le fichier en question est de le sauvegarder. |
| ex2 | Le but de cet exercice est de re utiliser ce qui a etait vu dans l'exercice 1 mais de gerer une exceptions et de recuperer l'argument avec autre que input() |
| ex3 | Le but de cet exercice est de voir plusieurs notion comme with, les conditions et les exceptions. |

---

## Instructions

Lancer l'exercice voulue dans le terminal.
### Complitation
```bash
python3 ft_ancient_text.py test.txt
```
